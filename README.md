# NETWORKWALKS – WEEK 3 PROJECT
## PASSWORD CRACKING | CYBERSECURITY & ETHICAL HACKING

### Project Overview
This repository documents my Week 3 practical exercises with NetworkWalks, focusing on password cracking, password hash extraction, and password security assessment.

The exercises involved using John the Ripper (JTR), Johnny GUI, and NetworkWalks online password-cracking tools to recover the password of a protected PDF file in a controlled training environment.

### Project Objectives
- Understand password hashing and password recovery.
- Learn how password hashes are extracted from protected PDF documents.
- Gain practical experience using password security assessment tools.
- Understand the risks associated with weak passwords.
- Appreciate the importance of strong password practices.

### Module 1: Password Cracking with John the Ripper (JTR)

**Tools Used:**
- John the Ripper
- Johnny GUI
- Online PDF Hash Extractor
- Windows PC

**Activities Performed:**
1. Downloaded and configured John the Ripper and Johnny GUI.
2. Extracted the password hash from the protected PDF.
3. Saved the extracted hash in a text file.
4. Loaded the hash into Johnny.
5. Initiated the password recovery process.
6. Successfully recovered the password.
7. Verified the recovered password by opening the protected PDF.

### Module 2: Password Cracking with NetworkWalks Tools

**Tools Used:**
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web Browser
- Windows PC

**Activities Performed:**
1. Uploaded the protected PDF to the NetworkWalks Hash Calculator.
2. Extracted and copied the PDF hash.
3. Opened the NetworkWalks Password Cracker.
4. Submitted the extracted hash.
5. Initiated the password recovery process.
6. Successfully recovered the password.
7. Verified the recovered password by opening the protected PDF.

### Key Learning Outcomes
- Understanding the difference between hashing and encryption.
- Understanding how password hashes are extracted and assessed.
- Practical exposure to John the Ripper and Johnny GUI.
- Experience using browser-based password security assessment tools.
- Understanding why weak and predictable passwords create security risks.
- Recognizing the importance of strong password policies.
